# SOWPODS dictionary

Place a newline-separated `sowpods.txt` file in this directory for fully offline use.
The app otherwise downloads the list once at runtime from:

https://github.com/kamilmielnik/scrabble-dictionaries/tree/master/english

The word list is intentionally not copied into this repository without its
licensing/provenance being reviewed. The UI also accepts a local text file if
the runtime cannot reach GitHub.
